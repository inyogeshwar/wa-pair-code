    HTTP API

    Same endpoints the page uses. JSON in, JSON out.

    POST /api/pair
    { "number": "919876543210" } → session with code
    POST /api/qr
    → session with a qr PNG data URL
    GET /api/session/:id
    → current status, refreshed QR, expiry
    GET /api/session/:id/download
    → zip of the auth files (only when status=paired)
