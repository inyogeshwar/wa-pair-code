Generate a pairing code or scan a QR, then download the auth files for your Baileys bot. Sessions live in memory and expire on their own.

  • Pair code or QR Two ways to link, one small API.
  • Session download Drop the files into your bot's auth/.
  • Nothing persisted No database. Temp files are wiped on expiry.

Codes are valid for about two minutes. Never share a pairing code or a downloaded session with anyone.

    HTTP API

    The same endpoints this page uses. JSON in, JSON out.

    POST /api/pair
    { "number": "919876543210" } → session with a code
    POST /api/qr
    → session with a qr PNG data URL
    GET /api/session/:id
    → status, refreshed QR, expiry
    GET /api/session/:id/download
    → zip of the auth files (only when status=paired)
